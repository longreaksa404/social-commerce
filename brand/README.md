# Oak brand files

Picked by the founder on 2026-10-15. Navy is #1f3350.

- `oak-acorn.svg`: the acorn, tilted. Oak Solutions' logo, and Oak Order's
  icon wherever the name doesn't fit. The same shape as
  `frontend/src/components/OakMark.tsx`.
- `oak-acorn-on-navy-1024.png`: white acorn on navy, for a profile photo
  (Facebook, Telegram crop it round).
- `oak-acorn-1024.png`: navy acorn on white.
- `oak-solutions-one-line.png`: "Oak Solutions" on one line, for wide,
  short spaces (a website header, an email signature).
- `oak-solutions-stacked.png`: Oak over SOLUTIONS, for square spaces (the
  top of a letter or receipt, a Facebook cover, a banner, a slide).
- `oak-order-name.png`: Oak Order's name, the acorn's cap pressed onto the
  O. In the app it is `OakOrderName` (live text, so it stays sharp).

The text is Kantumruy Pro, the logo's letters (the app's own text is Noto
Sans Khmer and Inter since 2026-10-17; the name keeps Kantumruy Pro).

For the CapCut video template (docs/02_video_playbook.md, "CapCut template"),
which points at these files by their full path on the laptop, so don't move
them:

- `fonts/NotoSansKhmer-Bold.ttf`: the captions' font. CapCut's own font list
  has no Noto Sans Khmer. From notofonts/khmer, SIL Open Font License
  (`fonts/OFL.txt`).
- `video/silence-1s.mp3`: one second of silence, the template's sample audio
  clip (the voice MP3s are laid out from its settings).
